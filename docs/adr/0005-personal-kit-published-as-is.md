# A personal kit, published as is

`ai-workflow` is built for its author's own use and published for transparency, not as a product. Design choices follow that use case. Configuration covers only the trackers and VCS hosts the author actually uses or plans to use; any other is described in prose rather than given its own template. There is no compatibility promise before 1.0. Requests to support more trackers, harnesses or workflows are out of scope unless the author needs them. Anyone else can use the kit as is or fork it.
